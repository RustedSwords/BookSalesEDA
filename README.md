# 📚 Books Data Analysis

This repository contains an exploratory data analysis (EDA). The dataset includes various attributes like titles, authors, genres, ratings, and more. This project aims to extract insights from the data and demonstrate proficiency in data wrangling, visualization, and modeling using Python.

## 📁 Files

- `Books_Data_Clean.csv`: Cleaned dataset used for analysis.
- `Notebook.ipynb`: Jupyter notebook containing all data preprocessing, visualization, and model development steps.

## 🛠️ Tools & Technologies

- **Python**  
- **Pandas** – data manipulation
- **NumPy** – numerical operations
- **Matplotlib & Seaborn** – data visualization
- **Jupyter Notebook** – development environment

## 📊 Key Tasks

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Visualizations (e.g., distribution of ratings, top authors, genre analysis)
